# Fretless

Your music. Your pace. An advertising-free, account-free Guitar Pro library and practice space. Imported music remains on your device; nothing is uploaded.

Live site: https://broderickmiller.github.io/Fretless-Guitar-Tabs/

## Develop

Node.js 24 and npm are required.

```sh
npm ci
npm run dev
```

Open the printed URL, including `/Fretless-Guitar-Tabs/`.

```sh
npm run typecheck
npm run lint
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

## Features

- Multiple-file and desktop drag-and-drop import; content-based duplicate detection.
- IndexedDB persistence; title/artist search, format/instrument/tuning filters, favourites and recently played sorting.
- Original-file download and removal, with clear browser-storage failure messages.
- Lazy-loaded alphaTab notation, track selection, actual score playback, seek and speed control.
- Measure-range looping, metronome, count-in, track mute/solo/volume and distraction-free practice layout.
- Responsive dark/light interface, keyboard focus and touch controls.
- Installable PWA. Application, notation fonts and SoundFont are precached, so imports can render and play offline after the initial cache completes.

Import accepts `.gp3`, `.gp4`, `.gp5`, `.gpx` and `.gp` for validation by the installed alphaTab parser. Only the original GP7 fixture has been verified end to end so far. Acceptance of an extension is not a guarantee for every historical variant. See `docs/roadmap.md` for the compatibility matrix and verification limits.

`fixtures/first-light.gp` is an original four-measure exercise, generated by `node scripts/create-fixture.mjs`, for reproducible import and playback testing. It contains no commercial arrangement.

## Your library and privacy

Files and metadata are saved in this browser's IndexedDB, never LocalStorage. The only LocalStorage preference is the colour theme. No analytics, tracking SDKs, account, external font service or mandatory provider is used. Browser storage can be evicted; retain original files and use the download control to keep copies. Clearing site data or changing browsers/devices does not carry the library over.

The first online visit downloads approximately 5.5 MB of offline assets, including notation and audio. Wait for caching to finish before relying on offline use. A browser may restrict autoplay until you press Play. Installation depends on browser and operating-system support.

## Deploy

Pushes to `main` run `.github/workflows/deploy.yml`: reproducible installation, TypeScript, ESLint, Vitest, build, desktop/mobile Chromium browser tests, Pages artefact upload and deployment. Pull requests run the same checks without publishing. After deployment, a separate job repeats the browser suite against the public Pages URL, including offline reload and playback.

In **Settings → Pages → Build and deployment → Source**, select **GitHub Actions**. The Vite base is `/Fretless-Guitar-Tabs/`. Fonts, worker/worklet chunks, icons, SoundFont and the service worker resolve under that path. No secrets are needed by the application or deployment workflow.

## Import from a URL

Choose **Import from URL** and paste an HTTPS link to a directly downloadable Guitar Pro file, or drop the link into the library. The file is validated and saved in IndexedDB like a local import; the source link is retained without query tokens or fragments. The host must allow cross-origin browser downloads. There is no proxy, account-cookie forwarding or tab-page scraping. Downloads have a 30 MB limit and a 30-second timeout, with a cancel control.

Songsterr and Ultimate Guitar page links show a source-specific guide instead of fetching or copying their scores. Songsterr currently lists Guitar Pro download as a Plus feature: use its official export/download option when authorised, then import the downloaded file. HTML/login pages, unavailable downloads and invalid files produce inline errors. New URL imports require internet access; saved imports remain usable offline.

## Paste tab text and library/practice preferences

Choose **Paste tab text**, add an optional title/artist, paste ASCII tablature, and select **Convert and save tab**. Include 4–8 string lines with fret numbers. Fretless infers tuning and carries section headings, tempo changes and repeat markers into a locally generated Guitar Pro file. The original text is retained in IndexedDB and can be exported alongside the generated `.gp` file.

Text tabs usually omit precise rhythm. Conversion estimates timing on a 4/4, sixteenth-note grid; bends, slides, hammer-ons and other expressive techniques are simplified. This is shown in the player. Conversion is limited to one million characters, 400 measures per track and 6,000 notes, and rejects oversized music instead of silently truncating it.

URL import also converts plain-text and HTML text-tab pages when the source allows browser reads. HTML is inspected inertly; no page scripts or embedded resources are executed. Existing restrictions on provider pages remain. Only import content you are permitted to use.

The library offers persistent grid/list views, a continue-practising rail, recently-added sorting and a text-format filter. **Settings** controls dark/light/system theme, reduced motion, default notation layout/display, playback speed, metronome, count-in and track-panel visibility. Storage settings show local file usage and browser quota, with an explicit confirmation before clearing the library.

The score player supports page/line layout, notation/tab/both display, multiple visible tracks, mixer reset, source conversion notes, section jumps, previous/next measure and current-measure/whole-song loops. Keyboard shortcuts: Space play/pause; Esc stop; arrows previous/next measure; `[`/`]` speed; L loop; M metronome. Shortcuts do not intercept typing or focused controls.
